Glossary

HTML
The standard markup language used to create web pages.
CSS
The language used to describe the style and layout of web pages.
JavaScript
A scripting language that enables dynamic and interactive web content.
Element
A component of an HTML document, defined by tags like <p> or <h1>.
Attribute
Provides additional information about an HTML element, like `href` in a link.
